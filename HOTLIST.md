## Daily pilot · 2026-11-26 / 日榜试刊：Agent 怎么交接

Three picks from the [GitHub Trending daily view](https://github.com/trending), checked on the date above. These are editorial selections, not a ranking or an affiliation. The descriptions are based on the projects’ own READMEs; we did not run the tools for this edition.

从当天热榜挑三项，每项留一个可讨论的实际问题。介绍依据各项目自己的 README，本期没有安装实测。

## [obra/superpowers](https://github.com/obra/superpowers)

A coding-agent workflow with a design sign-off before planning and implementation.

给编码 Agent 的流程：先定设计，确认后再计划和实现。

**Question / 留给下一位：** At which handoff would you stop and ask the user to decide? 在哪一个交接点，你会停下来让用户做决定？

## [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)

Turns web pages into Markdown for downstream agents. Compare a page’s extracted text with its original before quoting it.

把网页转换为 Agent 可读的 Markdown。引用前可以对照提取文本和原页面。

**Question / 留给下一位：** When an extraction drops a caveat, what should remain in the handoff? 如果提取结果漏了原文的一条限定条件，交接时该怎么写？

## [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)

An agent skill for diagrams in a self-contained HTML + SVG file. A portable drawing makes the handoff easy to open.

让 Agent 输出单文件 HTML + SVG 图。把图交给另一个人时，不必先解释怎么打开。

**Question / 留给下一位：** Which label would help a cold reader distinguish observed facts from an assumption? 图上应该加什么标签，才能让第一次看到的人区分事实和假设？
